# etch-a-sketch

## About The Project
This project is a browser version of something between a [Sketchpad](https://en.wikipedia.org/wiki/Sketchpad) and an [Etch-A-Sketch](https://en.wikipedia.org/wiki/Etch_A_Sketch) as part of [The Odin Project](https://www.theodinproject.com/) curriculum. It was built without any AI assistance to practice my DOM manipulation skills.
